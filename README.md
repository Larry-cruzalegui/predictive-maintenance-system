# Sistema de Mantenimiento Predictivo - IoT & IA

Sistema integral de ingeniería de datos y machine learning para la predicción de fallos en maquinaria industrial, conectado a bases de datos relacionales y desplegado con una interfaz web interactiva.

##  Tecnologías Utilizadas
- **Python** (Lógica, procesamiento y automatización)
- **Streamlit** (Desarrollo de aplicación web interactiva)
- **SQL Server** (Gestión de base de datos relacional y almacenamiento de métricas)
- **Power BI** (Dashboard analítico para visualización de KPIs de mantenimiento)

##  Evidencias y Funcionalidades del Sistema
- **Monitoreo en Tiempo Real:** Visualización directa de temperatura, vibración y horas de operación de la maquinaria.
- **Simulador de Predicción en Vivo:** Interfaz interactiva para evaluar el riesgo de fallo inminente en base a parámetros operativos.
- **Historial de Sensores:** Tabla conectada directamente al motor de base de datos para auditoría de eventos.
